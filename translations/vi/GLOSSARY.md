# Thuật ngữ Go 101

Giữ nguyên các thuật ngữ tiếng Anh dưới đây khi dùng như khái niệm kỹ thuật. Bổ sung thuật ngữ mới khi đã thống nhất cách dùng; danh sách này là baseline, không phải whitelist cứng.

| English | Cách dùng trong bản dịch |
| --- | --- |
| goroutine | goroutine |
| channel | channel |
| slice | slice |
| map | map |
| interface | interface |
| method set | method set |
| type parameter | type parameter |
| type constraint | type constraint |
| zero value | zero value |
| garbage collection (GC) | garbage collection (GC) |
| runtime | runtime |
| Go toolchain | Go toolchain |
| data race | data race |
| memory model | memory model |
| happens-before | happens-before |
| panic / recover | panic / recover |
| defer | defer |

Các từ thông thường như *value*, *type*, *function*, *variable*, *pointer*, *memory* được dịch theo ngữ cảnh, trừ khi chúng là một phần của tên API hoặc identifier.
