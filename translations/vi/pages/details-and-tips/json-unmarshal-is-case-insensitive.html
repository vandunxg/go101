Hàm json.Unmarshal chấp nhận việc khớp key của object không phân biệt chữ hoa chữ thường

Ví dụ, chương trình sau in ra bar, thay vì foo.

package main

import (
	"encoding/json"
	"fmt"
)

type T struct {
	HTML string `json:"HTML"`
}

var s = `{"HTML": "foo", "html": "bar"}`

func main() {
	var t T
	if err := json.Unmarshal([]byte(s), &t); err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println(t.HTML) // bar
}

Tài liệu của hàm json.Unmarshal ghi rằng "ưu tiên khớp chính xác nhưng cũng chấp nhận khớp không phân biệt chữ hoa chữ thường". Vì vậy, cá nhân tôi cho rằng đây là một bug trong implementation của hàm json.Unmarshal, nhưng Go core team không nghĩ vậy.
