Các compiler của Go sẽ tự động chèn một số dấu chấm phẩy vào code

Hãy xem một chương trình nhỏ:

package main

func foo() bool {
	return false
}

func main() {
	switch foo()
	{
	case false: println("False")
	case true: println("True")
	}
}

Output của chương trình trên là gì? Hãy suy nghĩ một lúc.

False? Không, nó in ra True. Ngạc nhiên không? Chẳng phải function foo luôn return false sao?

Đúng là function foo luôn return false, nhưng điều đó không liên quan ở đây.

Các compiler sẽ tự động chèn một số dấu chấm phẩy vào code trên như sau:

package main

func foo() bool {
	return false;
};

func main() {
	switch foo();
	{
	case false: println("False");
	case true: println("True");
	};
};

Bây giờ, có thể thấy rõ rằng biểu thức switch (true) đã bị lược bỏ. Khối switch thực sự tương đương với:

	switch foo(); true
	{
	case false: println("False");
	case true: println("True");
	};

Đó là lý do chương trình in ra True.

Để biết các quy tắc tự chèn dấu chấm phẩy chi tiết, vui lòng đọc bài viết này.
