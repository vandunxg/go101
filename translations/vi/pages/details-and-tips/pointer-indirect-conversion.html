Giá trị của hai named pointer type khác nhau có thể được convert gián tiếp sang type của nhau nếu base type của hai type có cùng underlying type

Nhìn chung, giá trị của hai pointer type không thể được convert sang nhau nếu underlying type của hai pointer type khác nhau. Ví dụ, 4 conversion trong code sau đều không hợp lệ.

package main

type MyInt int
type IntPtr *int     // underlying type là *int
type MyIntPtr *MyInt // underlying type là *MyInt

func main() {
	var x IntPtr
	var y MyIntPtr
	x = IntPtr(y)       // lỗi
	y = MyIntPtr(x)     // lỗi
	var _ = (*int)(y)   // lỗi
	var _ = (*MyInt)(x) // lỗi
}

Mặc dù không thể thực hiện trực tiếp 4 conversion trên, chúng có thể được thực hiện gián tiếp. Điều này dựa trên thực tế rằng các conversion sau là hợp lệ.

package main

type MyInt int

func main() {
	var x *int
	var y *MyInt
	x = (*int)(y)   // hợp lệ
	y = (*MyInt)(x) // hợp lệ
}

Lý do hai conversion trên là hợp lệ là giá trị của hai unnamed pointer type có thể được convert sang type của nhau nếu base type của hai type có cùng underlying type. Trong ví dụ trên, base type của các type của x và y là int và MyInt, chúng có cùng underlying type là int, nên x và y có thể được convert sang type của nhau.

Nhờ thực tế vừa đề cập, giá trị của IntPtr và MyIntPtr cũng có thể được convert sang type của nhau, dù các conversion như vậy phải được thực hiện gián tiếp, như trong code sau.

package main 

type MyInt int
type IntPtr *int
type MyIntPtr *MyInt

func main() {
	var x IntPtr
	var y MyIntPtr
	x = IntPtr((*int)((*MyInt)(y)))     // hợp lệ
	y = MyIntPtr(((*MyInt))((*int)(x))) // hợp lệ
	var _ = (*int)((*MyInt)(y))         // hợp lệ
	var _ = (*MyInt)((*int)(x))         // hợp lệ
}
